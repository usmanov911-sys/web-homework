# Домашнее задание: веб-приложение без фреймворков

## Цель
Закрепить понимание работы HTTP «под капотом»: написать простой веб-сервер
на встроенном модуле `http.server` и сверстать страницы с использованием Bootstrap.

## Изменения
- Добавлены HTML-шаблоны с Bootstrap (header, body, footer):
  - `index.html` — главная страница
  - `contacts.html` — страница контактов с формой
  - `404.html` — страница ошибки 404
  - `500.html` — страница ошибки 500
- Реализован сервер `server.py` на чистом Python:
  - Обрабатывает GET-запросы и возвращает HTML с `Content-Type: text/html`
  - Читает файлы через контекстный менеджер `with open()`
  - Обрабатывает POST-запросы и выводит данные в консоль
  - Возвращает 404 для неизвестных маршрутов
